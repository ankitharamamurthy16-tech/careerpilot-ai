# CareerPilot AI

Create a mobile-first Progressive Web Application (PWA) called CareerPilot AI.

It is an AI-powered personalized placement preparation application for college students.

Important requirements:

Design primarily for Android mobile screens, but make it responsive on laptops.

Use a premium modern design with navy blue, white and violet.

Create a professional splash screen with CareerPilot AI branding.

Create student registration and login screens.

Create a mobile dashboard with bottom navigation.

Dashboard sections: My Assessment, Code Decoder, Communication Coach, Career Roadmap, Projects, Resume Builder and Campus Community.

Display student progress, skill scores, daily tasks and weekly streaks.

Use realistic sample data initially.

Make the navigation and buttons functional.

Structure the application so we can connect a database and AI services later.

Make the application installable as a PWA with an app icon and full-screen mobile experience.

First build the application foundation and dashboard. Do not attempt to build every advanced feature yet.
